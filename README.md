# Alien Case Lights

Control the RGB lighting of an Alienware Area-51 R2 case from any Windows PC, without Alienware Command Center. Pick a color on the wheel, choose an effect, and the case follows live.

## Build

Requires the .NET 10 SDK.

```powershell
dotnet run --project AlienCaseLights.App -c Release
```

Close Alienware Command Center first so it doesn't fight over the lights.
